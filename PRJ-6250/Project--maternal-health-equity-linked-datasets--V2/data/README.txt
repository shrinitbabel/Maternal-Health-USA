README
Description:
This project links a variety of datasets at the geographic FIPS (county) level to enable maternal health equity research. Data cover a multi-year period across the United States, allowing research and comparison in steady state as well as disasters. Data include demographics, social vulnerability index, hospital utilization for pregnancy-related diagnoses, and travel time to hospitals with varying levels of obstetrics care. Researchers, healthcare providers, and health policy experts can use the data to identify needs and interventions to improve maternal morbidity and mortality, health outcomes, and healthcare utilization related to maternal health equity. The project is unique in that nationwide data are linked for the first time and made publicly available for research. While the majority of the data sources are publicly available, this is the first time they are linked to enable researchers to look broadly across usage/utilization. We also introduce a novel measure on travel time to hospitals/maternal care services for all counties/FIPS codes across the United States, which is only available in this dataset.
File Description:
The main data file is  Maternal Health HCUP SV CENSUS TIME.csv . This .csv file can be used in a wide variety of software programs for data visualization and analysis. The identical data are also provided in formats useable in a variety of common software programs including R (Maternal Health HCUP SV CENSUS TIME.rdata), Stata (Maternal Health HCUP SV CENSUS TIME.dta), SAS (Maternal_Healthsas7bdat), and SPSS (Maternal Health HCUP SV CENSUS TIME.sav). While the data in each file format is identical, we are providing multiple formats to make the data more easily useable for researchers who have subject matter expertise but may be less familiar with other data analysis software packages.
A codebook consisting of a data user guide, data sources, methods for combining the datasets, and information on missing data, as well as descriptive tables, are included in the combined codebook (Combined Codebook.docx).
A table of variables included in the datasets is provided in Microsoft Excel format, but can be opened in other software (Table of Variables.xlsx).
Example syntax that can be used with the dataset are provided in Stata formats as Stata-Do files (Maternal Health Data Cleaning.do and Maternal Health Data Codebook Generation.do). These files also describe how the data were cleaned and how the codebook was generated. However, neither these files nor this program are necessary to use the dataset.
